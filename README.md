# android_showcase

This repository contains a collection of various Android projects demonstrating different functionalities and techniques utilized in Android application development.

## Projects Overview

### 1. EncryptedDataStore
- **Description**: A sample project demonstrating how to use the Encrypted Data Store for securely storing sensitive information in Android.
- **Key Features**:
  - Secure storage of key-value pairs.
  - Easy integration into your Android application.

### 2. Fetch_Location
- **Description**: This project showcases how to fetch location data using the Google Location Services API.
- **Key Features**:
  - Real-time location tracking.
  - Simple UI for displaying current location.
  - Demonstrates best practices for handling location permissions.

### 3. NdKCounterApp
- **Description**: An application that demonstrates the integration of the Native Development Kit (NDK) to run C++ code within an Android app.
- **Key Features**:
  - Performance improvement using native code.
  - Insights into JNI (Java Native Interface) for communication between Java and C++.

### 4. ChatExample
- **Description**: A basic chat application implemented in Android using Firebase for real-time messaging.
- **Key Features**:
  - User authentication with Firebase Auth.
  - Real-time database functionality to send and receive messages.
  - Clear example of utilizing Firestore for data storage.

## Repository Structure
This repository is organized to facilitate easy navigation and contribution. Here's a breakdown of the folder structure:

```
/android_showcase
    ├── EncryptedDataStore/
    ├── Fetch_Location/
    ├── NdKCounterApp/
    ├── ChatExample/
```

Each project folder contains source code, a README file specific to that project, and relevant documentation.


This structure and language composition reflects a strong focus on modern Android development practices, utilizing Kotlin as the primary programming language while still integrating necessary HTML for any UI components.
